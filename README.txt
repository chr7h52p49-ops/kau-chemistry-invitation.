موقع دعوة تفاعلي - كلية العلوم / قسم الكيمياء - جامعة الملك عبدالعزيز

للمعاينة: افتح index.html في المتصفح.
لإظهار الشعار الرسمي دون أي تعديل: احفظ ملف الشعار الأصلي من صفحة الهوية الرسمية للجامعة باسم kau-logo.png وضعه بجانب index.html.
لا تغيّر ألوان الشعار أو نسبه. ألوان الواجهة مستندة إلى الهوية المؤسسية المنشورة للجامعة.

ملاحظة: نموذج التسجيل تجريبي محلي، لا يرسل البيانات ولا يخزنها.
النص الظاهر في التذييل: تمت هذه الدعوة بواسطة مها الردادي

للنشر على GitHub Pages:
1) أنشئ مستودعًا جديدًا في GitHub.
2) ارفع index.html و kau-logo.png.
3) Settings > Pages > Deploy from a branch > main > /(root) > Save.
